Add a Dynamic Form and use the Configure as Edit Form quick start to display the Position list of values.

Fetch the List of Values Record

  1. In the Source tab, under the dynamicLayouts node, open the data-description-overlay.json file of the layout (employmentWhenAndWhy in our example) and add a new property named positionsLov of type Object with fields for all the relevant list of value record properties that your application will need to use.

  2. In the Event Listeners tab of the Designer, add a transient value event listener to the Dynamic Form so that whenever a value in the list of values changes, the whole record is fetched and assigned to the positionsLov property.

    This makes the list of values record accessible to the Dynamic Form and its business rules. For the transient value event listener to work it needs to store, at the page level, the last value and execute the REST call only when the value changes. See the action chain associated with the event listener for more details.

Create Business Rules

Create business rules that depend on the list of values record's positionsLov property.

In this example, there are two business rules, ruleOne and ruleTwo. Based on positionsLov.PositionCode, these rules update the value of the DummyField field with values from the fetched list of values record. That is, positionsLov.PositionName.
