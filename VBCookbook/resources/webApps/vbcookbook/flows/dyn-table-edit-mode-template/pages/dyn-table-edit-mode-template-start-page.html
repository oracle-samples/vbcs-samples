This recipe shows you how to apply a field template to a field in an in-line editable Dynamic Table, when the field is selected to edit. In this example, the field template has been applied to the hireDate field so that when the user selects it for inline editing, it displays as mm/dd/yy with a Calendar component to update the date instead of displaying the date with IntlDateTimeConverter (dateFormat as full), which is what appears when the field is in navigation mode.
