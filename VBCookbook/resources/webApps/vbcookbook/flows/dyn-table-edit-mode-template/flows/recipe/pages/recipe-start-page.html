Add a Dynamic Table to the page and click Configure Layout in the Quick Start tab of the Properties pane to add data to the table. To create the field template in edit mode (hireDate in our example), use $cell.editMode to check if the table is in edit mode and apply the template if it is: 

<template id="hireDateTemplate">
  <oj-bind-if test="[[ $cell.mode === 'navigation' ]]">
    <oj-bind-text value="{{ $value }}"></oj-bind-text>
  </oj-bind-if>
  <oj-bind-if test="[[ $cell.mode === 'edit' ]]">
    <div class="oj-helper-text-align-start" id="hireDate">
      <oj-input-date value="{{ $value }}" date-picker.show-on="userFocus" id="hire-date"></oj-input-date>
    </div>
  </oj-bind-if>
</template>
