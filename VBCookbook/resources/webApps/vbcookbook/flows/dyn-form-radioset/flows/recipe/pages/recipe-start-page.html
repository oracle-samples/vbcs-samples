Add a Dynamic Form and use the Configure as Edit Form quick start to display employee details. In this example, we use a Radio Button Set component (oj-radioset) with an Array Data Provider to change the value of the employmentStatus field.

Configure componentType and Data Provider for the Employee Status Field

  1. In the Source tab, open the Employee layout's data-description-overlay.json file and, using addMetadata or replaceMetadata, set the componentType of employmentStatus field to oj-radioset and configure the dataProvider as ojs/ojarraydataprovider. 
    "employmentStatus": {
  "type": "string",
  "labelHint": "Employment Status",
  "componentType": "oj-radioset",
  "dataProvider": {
    "factory": "ojs/ojarraydataprovider",
    "parameters": [
      [
        {
          "value": "active",
          "label": "Active"
        },
        {
          "value": "pending",
          "label": "Pending"
        },
        {
          "value": "inactive",
          "label": "Inactive"
        }
      ],
      {
        "keyAttributes": "value"
      }
    ]
  }
},

    In this example, the data provider uses an Array Data Provider with static data. A Service Data Provider can also be configured in this way.

  2. The default arrangement of options in a Radio Button Set component is vertical. That is, a new option appears underneath the previous option. The Radio Button Set component's oj-choice-direction-row class lays out options in a row. To use this class, in the JSON tab of the dynamic form's Employee layout, add the class to the employeeStatus field, as shown in the following example. 
    "displayProperties": [
  "firstName",
  "lastName",
  {
    "employmentStatus" :{
      "class" : "oj-choice-direction-row"
    }
  }
]
