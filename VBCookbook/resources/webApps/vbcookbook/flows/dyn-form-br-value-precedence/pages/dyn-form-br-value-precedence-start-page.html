This recipe demonstrates the value precedence property (JsonMetadata.valuePrecedence) of a field in a dynamic form. This property controls how an editable field behaves when both user input and system calculations can update its value.
In this example, the currencyAmountVP field in the Expense layout is initially assigned an incorrect value. Since its valuePrecedence property is set to calculation, Business Rules do not recalculate it, and the incorrect value remains unchanged—unless the value of currency field is modified.
Users can also manually update the value of currencyAmountVP field. When they do, Business Rules will respect their input and will not overwrite it—unless the value of currency field changes again.
