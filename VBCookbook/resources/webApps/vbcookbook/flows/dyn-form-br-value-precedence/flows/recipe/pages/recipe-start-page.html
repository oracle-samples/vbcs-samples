Add a Dynamic Form to display the appropriate fields (Expense Type, Amount in USD, and so on) using the Expense dynamic layout.

Update Dynamic Form Configuration

  1. In the Variables tab of the Designer, create a page variable named expenseObjectContext of type Object, and then add a field named exchangeRate of type Number within this page variable.
  2. In the JSON tab, update the metadata section to pass expenseObjectContext as the objectContext into the business rules within the page's JSON. 
      "metadata": {
    "expenseJsonMetadata": {
      "type": "vb/DynamicLayoutMetadataProviderDescriptor",
      "defaultValue": {
        "path": "dynamicLayouts/Expense",
        "objectContext": "[[ $variables.expenseObjectContext ]]"
      }
    }
  },
  3. In the Page Designer, select the dynamic form component and in the Events tab of the Properties pane add an ojRawValueUpdated event to listen to the current value change so that we can fetch the corresponding current exchange rate.
  4. In the action chain associated with the event (FormRawValueUpdatedChain), update the value of the exchangeRate field in the expenseObjectContext page variable if the value of the currency field changes. 
      if (event.previousValue.currency !== event.value.currency) {
    $variables.expenseObjectContext.exchangeRate = undefined;
    // Use setTimeout to simulate that retrieval of exchange rate can be asynchronous.
    // In a real implementation, you would use REST call here.
    setTimeout(() => {
      if (event.value.currency === 'INR') {
        $variables.expenseObjectContext.exchangeRate = 84.4;
      } else if (event.value.currency === 'EUR') {
         $variables.expenseObjectContext.exchangeRate = 0.95;
        } else {
            $variables.expenseObjectContext.exchangeRate = 1;
          }
     }, 2000);
  }

Create Business Rules

  1. In the Layouts tab, open the Expense layout.
  2. In the Context tab, click + Object Context to create a new object context named exchangeRate of type Number.
  3. In the Business Rules tab, click the + icon in the Form Rules section to create a new business rule named Currency Change with Rule Type as Regular.

  4. In the Currency Change rule, set the value of the currencyAmount field to an expression:

    [[ $objectContext.exchangeRate ? ($fields.baseAmount.value() * $objectContext.exchangeRate) : undefined ]]
