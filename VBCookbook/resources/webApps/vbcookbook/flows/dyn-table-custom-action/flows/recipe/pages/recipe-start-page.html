Add a dynamic table to the page. In the Properties pane, click Configure Layout in the Quick Start tab to add data to the table.

Create a Custom Action Column

  1. In the Fields tab of the Employee layout, create a custom field named Actions, set its type to String, and assign it a placeholder value.

    This field serves as a placeholder for the custom action. We add it as a column in the dynamic table while using a custom field template to render the custom actions, which in this example, are icon buttons. It is important to set the field's placeholder value, otherwise the dynamic table attempts to retrieve the field's value from the backend when the field does not yet exist.

  2. In the rule set for the dynamic table layout, add the Actions field as the last column.
  3. In the Templates tab of the Employee layout, create a field template with one button for an edit operation and a second button for a delete operation.

  4. In the Events tab of the Employee layout, create a custom event named customAction with action and rowKey parameters.

    Select the Emit event to page checkbox. The page listens for these events, and the dynamic table will fire them with the payload, providing information about which action should be executed on which row, identified by its key. If additional record information is necessary (for example, the eTag value of the record), it can be added to the payload similar to the rowKey parameter.

  5. In the Events tab of the Properties pane for the edit operation button that you added to the field template, add an ojAction event listener and pass the following input parameters to the action chain that this event listener invokes:

    • Input parameter named action with a value of edit
    • Input parameter named rowId with a value of {{ $current.row.id }}

  6. Similarly, for the delete operation button that you added, also add an ojAction event listener and pass the following input parameters to the action chain:

    • Input parameter named action with a value of delete
    • Input parameter named rowId with a value of {{ $current.row.id }}
  7. In both action chains, add a Fire Event action to trigger the customAction event, mapping the input parameters as follows:
    • action → action
    • rowId → rowKey
  8. In the Event Listeners tab of the page where you added the dynamic table component, add an event listener for the customAction event for the dynamic table.
  9. Within the event listener's action chain, add an If action to check the value of the action parameter and perform either an edit or delete operation accordingly.
