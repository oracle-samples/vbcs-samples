Add a Dynamic Table to the page. In the Properties pane, click Configure Layout in the Quick Start tab to add data to the table.

Disable editing for certain rows

  1. Create a JS function to disable the Edit action for certain rows using the rows' keys. In this example, 100, 102 and 104 are the keys of the rows for which we want to disable the Edit action: 
        rowEditable(item) {
      let disabledKeys = [100, 102, 104];
      if (disabledKeys.includes(item.metadata.key)) {
        return 'off';
      } else {
        return 'on';
      }
    }
  2. Assign the result of the rowEditable function to row.editable property of the dynamic table. The rows with rowKey 100, 102 and 104 now have the Edit action disabled.
