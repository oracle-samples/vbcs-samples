Add a Dynamic Table that displays columns with longer content, such as email, so that the content can be wrapped.

Column-Level Content Wrapping and Alignment

Add the oj-helper-overflow-wrap-anywhere and oj-helper-white-space-normal classes to the field that you want to wrap and add the oj-helper-text-align-end class to the field that you want to align in the layout.json file. The following example demonstrates how to content wrap the email field and right align the hireDate field: 

"layouts": {
  "default": {
    "layoutType": "table",
      "layout": {
        "displayProperties": [
          "fullName",
          {
            "email": {
              "class": "oj-helper-overflow-wrap-anywhere oj-helper-white-space-normal",
              "maxWidth": "10%"
            }
          },
          {
            "hireDate": {
              "class": "oj-helper-text-align-end"
            }
          },
          "phoneNumber",
          {
            "salary": {
              "readonly": true
            }
          }
        ],
        "fieldTemplateMap": {
          "fullName": "fullNameWrapped",
          "phoneNumber": "phoneNumberAlignment"
        }
      },
      "usedIn": [
        "isDefault18"
      ]
    }
  },

Note: The value of the class attribute will not be applied when the field is used in a field template. The field template is responsible for styling.

Cell-Level Content Wrapping and Alignment

Apply CSS to the field template of the fields that you want to content wrap and align. The following examples demonstrate how to content wrap the fullName field and left align the phoneNumber field respectively:

<template id="fullNameWrapped">
  <span style="white-space: normal; overflow-wrap: break-word">
  <oj-bind-text value="{{ $value }}"></oj-bind-text>
  </span>
</template>

<template id="phoneNumberAlignment">
  <div class="oj-helper-text-align-start">
  <oj-input-text value="{{ $value }}" label-hint="[[ $labelHint ]]"></oj-input-text>
  </div>
</template>
