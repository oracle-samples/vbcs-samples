The first time that the page renders, each table in the page renders data. Click Query That Returns No Results to view the custom messages implemented in the recipe for the scenario where a query returns no data. Open the recipe in Visual Builder to view the implementation. The following steps provide a high-level summary of how to implement this recipe.

Display Custom Text
  1. In the Code view of the page, set the Table component's msg-no-data sub-property as follows: 
    <oj-table translations.msg-no-data="My Custom No Data Message">
</oj-table>
Display Custom HTML Message
  1. Add a Cell Template slot named noData and write HTML with the message to display when the query fails to return data.
    2. <oj-table>
	<template slot="noData">
		<div>
			<span>There is no data to display.</span>
		</div>
		<div>
			<oj-button>Refresh Query</oj-button>
		</div>
	</template>
</oj-table>
