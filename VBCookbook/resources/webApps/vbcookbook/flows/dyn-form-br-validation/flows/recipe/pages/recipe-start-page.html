Add a Dynamic Form, and use the Configure as Edit Form quick start to display the appropriate fields (First Name, Department, and so on) using the Employee business object.

Add Validation

  1. In the Layouts tab, select the Employee dynamic layout.
  2. In the Validations tab for the Employee dynamic layout, click + Validation to create a validation rule named Check Department with Rule Type as Regular.

  3. In the Check Department rule, click the Edit button in the Conditions section, switch to Code view, and enter the following code:

    $fields.department.$numberValue() === 8

    This checks if the value of the department field is equal to 8. You can delete the Messages section for this rule.

  4. Hover over the Check Department rule in the Built-in Rules section and then click the + icon to create a nested rule under the Check Department rule. Name the rule Commission Percent Range with Rule Type set to Regular.

  5. In the Commission Percent Range rule, click the Edit button in the Conditions section, switch to Code view, and enter the following code:

    $fields.commissionPct.$numberValue() < 5 || $fields.commissionPct.$numberValue() > 20

    This checks that the value of the commissionPct field remains within the range of 5 to 20.

  6. In the Messages section, set the following values:
    • Summary to Commission Percent Range
    • Severity to Warning
    • Target Fields to Commission Percent
    • Detail to Commission should be between 5 to 20
