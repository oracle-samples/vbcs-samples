Add a Dynamic Form and use the Configure as Edit Form quick start to display the appropriate fields (Job Title, Currency, and so on) using the Job business object.

Update Label Hint for Minimum and Maximum Salary

  1. In the Layouts tab, select the Job dynamic layout.
  2. In the Fields tab for the Job dynamic layout (Job Fields), click + Custom Field to create a new custom field named currency of type String.

  3. Still in Job Fields, set the Label Hint values for the minSalary and maxSalary fields as [[ $functions.getMinSalaryLabel($fields.currency.value()) ]] and [[ $functions.getMaxSalaryLabel($fields.currency.value()) ]] respectively.

    Also add currency to the Referenced Fields property for both the minSalary and maxSalary fields.

    As an alternative to using the Properties pane, switch to the JSON view of Job Fields and add the following code in the replaceMetadata section to set the Label Hint and Referenced Fields properties.

    "replaceMetadata": {
  "maxSalary": {
    "labelHint": "[[ $functions.getMaxSalaryLabel($fields.currency.value()) ]]",
    "referencedFields": [
        "currency"
      ]
  },
  "minSalary": {
     "labelHint": "[[ $functions.getMinSalaryLabel($fields.currency.value()) ]]",
    "referencedFields": [
        "currency"
      ]
  }
}
  4. In the JSON view of Job Fields, set componentType as oj-select-single so that the currency field renders as a dropdown list. 
      . . .
  "addField": {
    "currency": {
      "type": "string",
      "labelHint": "Currency",
      "componentType": "oj-select-single",
      "dataProvider": {
        "factory": "ojs/ojarraydataprovider",
        "parameters": [
          [
            {
              "value": "eur",
              "label": "EUR"
            },
            {
              "value": "inr",
              "label": "INR"
            },
            {
              "value": "usd",
              "label": "USD"
            }
          ],
          {
            "keyAttributes": "value"
          }
        ]
      }
    }
  },  
  . . .
  5. In the JavaScript view of Job Fields, create the following functions to set the label hint values for the minSalary and maxSalary fields. 
    DataDescriptionModule.prototype.getMinSalaryLabel = function (currency) {
  return "Minimum salary in " + currency?.toUpperCase();
};

DataDescriptionModule.prototype.getMaxSalaryLabel = function (currency) {
  return "Maximum salary in " + currency?.toUpperCase();
};
