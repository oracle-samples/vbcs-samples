Add two Dynamic Tables to the page and click Configure Layout in the Quick Start tab of the Properties pane to add data to both tables. Use the same metadata and layout for both tables.

Configure the Drag Table

  1. In the General tab of the Properties pane, select Multiple for the Selection Mode, Row field.
  2. In Code view, add the following property to the table:
    dnd.drag.rows.data-types="application/ojtablerows+json"

Configure the Drop Table

  1. In the Variables tab, create a page variable named employeeDropListADP of type Array Data Provider.
  2. In the All tab of the Properties pane of the Page Designer, set the dynamic table Data property to [[ $variables.employeeDropListADP ]].
  3. In Code view, add the following properties to the table:
    . . . dnd.drop.rows.data-types="application/ojtablerows+json" dnd.drop.rows.drop="[[$functions.handleDropRows]]" . .

Create the Drag Handler

  1. In the JavaScript tab, add a module function named handleDropRows: 
                
handleDropRows(event, ui) {
  let dragData = event.dataTransfer.getData(
    'application/ojtablerows+json');

  if (dragData) {
    this.eventHelper.fireCustomEvent('dataDropped', {
      rows: JSON.parse(dragData).map(function(i) {
        return i.data
      }),
      startIndex: ui.rowIndex
    })
  }
};
  2. In the Events tab, create a page custom event named dataDropped with the following payload:
    • rows of type Array (object)
    • startIndex of type Number
  3. In the Event Listener's tab, add an event listener to the custom event dataDropped that creates an action chain named TableDropChain.
  4. Add Assign Variable actions to the action chain for each of the following variables. 
                
let data = $page.variables.employeeDropListADP.data;

const addData = data
  .slice(0, event.startIndex)
  .concat(event.rows)
  .concat(data.slice(event.startIndex));

$page.variables.employeeDropListADP.data = addData;
