Create Tree Structure Data for the Dynamic Table

  1. In the Variables tab of the Designer, create a page variable named employeeTreeData of type Any to store the tree structure data.
  2. In the Event Listeners tab, create a vbEnter event and an associated action chain named loadEmployeeData.
  3. In Code view of the Action Chains tab, include the following dependency: 
    define([
    'vb/action/actionChain',
      . . . 	
    "ojs/ojarraytreedataprovider"
   ], (
    ActionChain,
    . . . 
    ArrayTreeDataProvider
  ) => {
. . .
  4. In Design view of the Action Chains tab, add a Call REST action to the endpoint (Employee in our example), and set the appropriate Response Type to fetch the desired fields.
  5. Assign the result of the Call REST action to an Assign Variable action named employeeArray.
  6. Add a Call Function named convertArrayIntoTree with an input parameter to convert the employee array data into a tree structure format.
  7. Call the convertArrayIntoTree function and pass the employeeArray variable as a parameter and store the result of the function in a local variable named tree.
  8. Use an Assign Variable action that creates an instance of ArrayTreeDataProvider to convert the data from tree variable into a format which represents hierarchical data available from the array and stores the result into the employeeTreeData page variable.

Create a Dynamic Table that uses Tree Structure Data

  1. In the Page Designer, drag and drop the Dynamic Table component onto the page.
  2. In the Quick Start tab of the Properties pane, click Configure Layout.
  3. In the Configure Layout dialog that appears, choose the business object or REST endpoint that you want to use as the data source for the form, and click Next.
  4. In the Select Rule Set page of the Configure Layout dialog, click New Rule Set to define your own display logic, and enter a rule set label and ID, such as rowExpanderTableLayout RuleSet.
  5. In the Fields section, select the fields that the Dynamic Table component displays (fullName and so on), and click Next, and then click Finish.

  6. In Code view of the Page Designer, replace the value assigned to the data property with the page variable employeeTreeData:

    <oj-dynamic-table data="[[$variables.employeeTreeData]]" . . .
