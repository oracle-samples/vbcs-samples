Create a dynamic table

  1. Add a Dynamic Table to the page and use the quick start wizard to add the data to it.
  2. Set the table's selection-mode.row property to single and selection-required to true.
  3. Add a First Selected Row Event Listener to the table and assign the key of the selected row to a page variable rowId in the corresponding action chain.
  4. Add an oj-drawer-popup component to the page, which will contain the fragment.
  5. Add a button to the page on top of the table to handle opening and closing the drawer component

Create a fragment with dynamic form

  1. Create a fragment and add a dynamic form to it. Use the Configure as Edit Form quick start to display the values.
  2. Add this fragment inside the oj-drawer-popup component on the page. Surround it by oj-bind-if to conditionally remove it from the DOM when the drawer closes, and to re-add it when the drawer opens. This way, the fragment always has the updated values when the drawer re-opens.
  3. Pass the page variable rowId as an input parameter to the fragment to fetch the record of the selected row for editing.
