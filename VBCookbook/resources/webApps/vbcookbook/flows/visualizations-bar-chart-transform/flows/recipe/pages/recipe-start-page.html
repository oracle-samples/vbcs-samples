The Bar Chart component displays salary totals on the Y-axis and job titles on the X-axis. Before you bind data to the component, you need to fetch the data from the REST service and create the fields in an object, including total salary, using a JavaScript function. Finally, you use an Array Data Provider to hold the data and populate the chart component.

Create a Service Connection

Create a service connection using the employee endpoint that returns employee data (https://apex.oracle.com/pls/apex/sample_ords_rest/hr/employees).

 Create a Bar Chart Component
  1. In the Component Palette, drag a Bar Chart component and drop it onto the Page Designer. Do not assign any data to it yet.
  2. In the General tab of the Properties pane, select On for Stack Values.
 Create Variables, Event Listeners, and an Action Chain
  1. Create an ADP variable named transformedDataADP.
  2. In the Code view of the Page Designer, set the chart’s data attribute to this variable and set the value, group and series attributes for chart item to the value, group and series fields in the variable using oj-chart-item component.
  3. In the Event Listeners section, add a new vbEnter event that is called when the page loads.
  4. Add a new action chain called fetchDataFromService.
 Configure the Action Chain
  1. In the fetchDataFromService action chain, add a Call REST Endpoint action and select the employee endpoint you created earlier. Optionally set the limit query parameter to 1000 so that one call can fetch many records. By default, the ORDS REST service returns 5 records.
  2. Map the job and salary values from the REST response to flattenedArray variable.
  3. Using the array of data objects of flattenedArray variable, calculate the total salary and total employees count for a given job type, and add it to a new data array object named aggregatedData as shown below. 
    // create group, series, value based items for chart
let flattenedArray = [];
response.body.items.forEach(function (employeeRecord) {
  let chartItem = {};
  chartItem.group = employeeRecord.job;
  chartItem.series = employeeRecord.job;
  chartItem.value = employeeRecord.sal;
  flattenedArray.push(chartItem);
});

// create aggregate data items for chart
let groupByJobMap = new Map();

flattenedArray.forEach(function (employeeRecord) {
  // employeeRecord is the emp record with fields series (job), group (job), value (sal)
  if (groupByJobMap.has(employeeRecord.series)) {
    // aggregated data object with fields series (job), group (job), value (totalsalary) and count
    let aggregateDataObject = groupByJobMap.get(employeeRecord.series);
    aggregateDataObject.value =
      aggregateDataObject.value + employeeRecord.value; // total salary for given job
    aggregateDataObject.count = aggregateDataObject.count + 1; // count of employees
    groupByJobMap.set(employeeRecord.series, aggregateDataObject);
  } else {
    employeeRecord.count = 1; // initialize count=1
    groupByJobMap.set(employeeRecord.series, employeeRecord);
  }
});

let aggregatedData = Array.from(groupByJobMap, ([jobKey, jobRecord]) => ({
  group: jobRecord.group,
  series: jobRecord.series + " (" + jobRecord.count + " Employees)",
  value: jobRecord.value,
}));
  4. Add an Assign Variables action and set the data of the transformedDataADP variable to aggregatedData.
