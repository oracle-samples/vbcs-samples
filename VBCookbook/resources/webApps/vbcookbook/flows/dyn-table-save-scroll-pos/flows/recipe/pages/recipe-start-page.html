Add a Dynamic Table to the page and click Configure Layout in the Quick Start tab of the Properties pane to add data to the table.

Save and Restore the Scroll Position

  1. In the Designer's left navigator select the flow that contains your page and, in the Variables tab for the flow, create a flow-level variable named scrollPosition to save the scroll position across the flow.
  2. In the Designer's left navigator select the page where the user will navigate from and, in the Event Listeners tab, add an event listener named on-scroll-position-changed to track the scroll position.
  3. In the action chain for the on-scroll-position-changed listener, use an Assign Variable action to save the sub-properties of scroll-position to the scrollPosition flow-level variable. For example: 
    $flow.variables.scrollPosition.rowIndex = scrollPosition.rowIndex;
$flow.variables.scrollPosition.offsetY = scrollPosition.offsetY;
  4. In the Variables tab, create a page-level variable named scrollPositionPage and use it to set the scroll-position attribute of the dynamic table. Set the default value of this variable to the flow-level variable, scrollPosition.
