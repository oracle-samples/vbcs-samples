Imagine you have an edit form with button which takes long time to save changes. To make sure that the user does not click the button multiple times, you will create an action chain that disables the button until the operation completes.

Create a Form With a Button
  1. Create an input text (Form) and a button in the page.
  2. Create a variable disableButton of type Boolean to control disabled state of the button. Set this variable as the disabled property of the button, defaulted to false. The variable when set to true disables the button demonstrating that some backend operation is in progress.
  3. Create another variable buttonText of type String and use it to set the Label property of the button, defaulted to 'Add'.
Add an Event Listener and an Action Chain to Prevent Double Click
  1. In the Events tab of the Properties pane for the Button component, click New Event to create an ojAction event listener.
  2. In the action chain editor, add an Assign Variables action to map the two page variables that you created previously. Assign 'Processing...' to the buttonText variable and set the disableButton variable to true. This will disable the button.
  3. Perform your server action here, a dummy delay using a promise in this example.
  4. Once the server operation completes, use Assign Variables action to reset the buttonText and disableButton variables to 'Add' and false respectively.
