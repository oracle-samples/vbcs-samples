Add a Dynamic Table to the page and click Configure Layout in the Quick Start tab of the Properties pane to add data using the Employee endpoint to the table.

Implement Default Sorting in the Dynamic Table

  1. Define the default sort for the dynamic table by creating a page variable sort of type Object with two fields:

    • attribute with default value as firstName
    • direction with default value as descending

  2. Set the Persisted property of the sort page variable to Device if sort criteria needs to be stored across sessions or History if sorting should be preserved only when drilling into a child page and navigating back.

  3. Set the sortCriteria parameter of the dynamic table's Service Data Provider variable (employeeListSDP in this example) to the sort page variable created in Step 1. The sortCriteria is of type array, allowing sorting by multiple attributes such as firstName, lastName, email. The sort variable is an object which during assignment is converted into an array of objects.
    4. Note:

    If your SDP uses a customized fetch chain, the name of the parameter is not sortCriteria but requestTransformOptions.sort.

    The dynamic table's First Name column now sorts in descending order.

Preserve Sorting in the Dynamic Table

Oracle Visual Builder's Designer does not expose the ojSort event that the dynamic table needs to fire when sorting is applied to a dynamic table column, so you need to add this event manually to your page.

  1. In the JSON tab of your page, add the ojSort event under the eventListeners section. 
    "eventListeners": {
  . . . 
  },
  "ojTableSort": {
    "chains": [
      {
        "chain": "TableSortChain",
        "parameters": {
          "sort": "[[ $event.detail ]]"
        }
      }
    ]
  }
},
. . .
  2. In Code mode of the Page Designer, define the event for the dynamic table. 
     <oj-dynamic-table ... on-oj-sort="[[$listeners.ojTableSort]]"></oj-dynamic-table>

  3. Create an action chain named TableSortChain.

    This action chain is already referenced in the ojTableSort event listener's that we created in Step 1.

    Note: The action chain's name is case-sensitive, so use the exact case as the event listener code when creating the action chain.

  4. In Code mode of the action chain, add the { sort } parameter into the action chain's run function 
    async run(context, { sort }) {
  5. Add an Assign Variable action and select sort from the Variable dropdown list in the action chain's Properties pane.
  6. Set the value of the sort variable to: 
      {
    attribute: sort.header,
    direction: sort.direction,
  }
