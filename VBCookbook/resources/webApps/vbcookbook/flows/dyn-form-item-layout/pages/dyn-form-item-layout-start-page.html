This recipe demonstrates how to customize the layout of a dropdown list in a dynamic form.

The recipe uses Oracle JET Select Single components (oj-select-single) to render the dropdown lists that you see below (Department and Manager). Select Single components support the customization of the layout of the dropdown list items. In Example 1, the Department dropdown list uses a Table Item Layout to display multiple fields as columns (departmentName and totalSalary, in our example). In Example 2, the Department dropdown list uses a different layout, List Item Layout, so that multiple fields (departmentName, location etc.) are arranged in a list format within the dropdown list. In Example 3, the Manager dropdown list display value (< item-text>) is customized to concatenate different fields (firstName and email) into a single display value.
