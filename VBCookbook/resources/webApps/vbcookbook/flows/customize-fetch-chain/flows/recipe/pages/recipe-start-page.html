Create a boolean variable to control the Button component's disabled property and a string variable to change the Button component's label to a message for the user. Use an Assign Variables action in the action chain to disable the Button component and display a status message while the action chain performs its other actions. On completion of these actions, use another Assign Variables action to enable the Button component again.

Create a Form with a Button Component
  1. Add an Input Text and a Button component to the page.

  2. Create a variable disableButton of type Boolean to control the Button component's disabled property.

    Default disableButton to false. When true, it disables the Button component.

  3. Create another variable buttonText of type String and use it to set the Label property of the Button component.
Add an Event Listener and an Action Chain to Prevent Double Click
  1. In the Events tab of the Properties pane for the Button component, click New Event to create an ojAction event listener.
  2. In the action chain editor, add an Assign Variables action to map the two page variables that you created previously. Assign 'Processing...' to the buttonText variable and disable the Button component by setting the disableButton variable to true.

  3. Add the other actions to the action chain.

    In our example, we use a Call Function action that sets a timeout.

  4. Add another Assign Variable action as the last action in the chain to re-enable the Button component and use its default label (Add).
