A Table component displays department data. A Checkbox Set component with an event listener updates the selectionRows variable that holds an array of selected department rows. getEnhancedDataProvider() API is used to retrieve the cached rows data avoiding new REST calls on every selection change.

Create a Department Table

You add a Table component to your page, bind it to department data, and add a Checkbox Set that you'll later use to select departments.

  1. In the Component Palette, drag a Table component and drop it on the page.
  2. Use the Table component's Add Data Quick Start to bind your table to department data.
  3. In the Bind Data page, select the following department fields:
    • Department Id
    • Department Name
    • Manager Id
    • Location Id
  4. This create a new variable departmentListSDP of type Service Data Provider.
  5. In the General tab of the Properties pane for the Table select Multiple for the Selection Mode, Row property.

Read and Select Rows

  1. In the Variables tab, create a new variable named selectedRows of type Any.
  2. In the Event Listener tab, add the vbEnter event listener to the page and name the associated action chain initializeVariables.
  3. In the Code view of the action chain, initialize selectionRows as follows: 
    $page.variables.selectedRows = { "row": new keySet.KeySetImpl(), "column": new keySet.KeySetImpl() };
    Remember to add the definition for 'ojs/ojkeyset'.
  4. In the Data tab of the Properties pane for Table, set the Selected property to {{ $variables.selectedRows }}.
  5. To control row selection programmatically, set the selectedRows variable as follows: 
    // reset the current selection to none
$page.variables.selectedRows = { "row": new keySet.KeySetImpl(), "column": new keySet.KeySetImpl() };
 
// select only specific key rows with keys 1,3
$page.variables.selectedRows = { "row": new keySet.KeySetImpl([1,3]), "column": new keySet.KeySetImpl() };
 
// access selected row keys
let rowSelection = $page.variables.selectedRows.row;
if (rowSelection.isAddAll()) {
  // all rows are selected and no row keys will be provided
  // as table may not have all of them displayed anyway.
  // check also Array.from(rowSelection.deletedValues()) for individual
  // rows which may have been excluded from "all rows selected" list
} else {
  // array of row keys:
  const rowKeys = Array.from(rowSelection.values());
}
 
// to check if any row is selected or not
let rowSelection = $page.variables.selectedRows.row;
return rowSelection.isAddAll() || rowSelection.values().size > 0;

Access Data for the Selected Rows

To access data for the selected rows, we need to fetch it from the data provider. The departmentListSDP is stateless and does not cache row data, so the Table cannot be relied on to return up-to-date data without a REST call to the backend service. To avoid unnecessary REST calls, we'll make use of DataProviderFactory.getEnhancedDataProvider to create an enhanced data provider (enhancedDP) that wraps departmentListSDP and caches row data, so that data for selected rows is returned from an in-memory cache.

  1. In the Variables tab, create a new variable named enhancedDP of type Any.
  2. In the Code view of the initializeVariables action chain, initialize enhancedDP as follows: 
    // initialize the enhancedDP using the departmentListSDP
$page.variables.enhancedDP = DataProviderFactory.getEnhancedDataProvider( $page.variables.departmentListSDP, {fetchFirst :
{ caching: 'visitedByCurrentIterator' }});
    Remember to also add the definition for ojs/ojdataproviderfactory at the start of the action chain: 
    define([
  . . .
  'ojs/ojdataproviderfactory',
  'ojs/ojkeyset'
], (
  . . .
  DataProviderFactory,
  keySet
) => {
  3. In the All tab of the Properties pane for Table, set the Data property to [[$page.variables.enhancedDP]].
  4. In the Events tab of the Properties pane for Table, add a selected event listener and name the associated action chain TableSelectedChangeChain.
  5. In the action chain, access the selected row keys using the selected.row.keys input parameter and access row data using the enhancedDP variable's fetchByKeys method, as shown below: 
    async run(context, { keys, selected }) {
  const { $page, $flow, $application } = context;
 
  let isAllSelected = selected.row.keys.all;
  let selectedKeys = selected.row.keys.keys;
  let uncheckedKeys = selected.row.keys.deletedKeys;
 
  if (isAllSelected === true) {
    let selectionString = "All rows are selected.";
 
    // check for unselected keys
    if (uncheckedKeys.size > 0) {
      selectionString += " except rows with key : " + Array.from(uncheckedKeys).toString();
    }
 
    $page.variables.currentSelectionString = selectionString;
  }
  else if (selectedKeys.size === 0) {
    // all check box is not selected, check if any row is selected at all
    $page.variables.currentSelectionString = "Nothing selected.";
  }
  else {
    // only few specific rows are selected by user, get the row data for each.
    $page.variables.enhancedDP.fetchByKeys({ keys: keys }).then(fetchResult => {
      let rowsData = (fetchResult.results);
 
      let selectionString = "Selected rows data: ";

      rowsData.forEach(rowItem => {
        selectionString += "\n{'id':'" + rowItem.data.id;
        selectionString += "','departmentName':'" + rowItem.data.departmentName;
        selectionString += "','location':'" + rowItem.data.location;
        selectionString += "','manager':'" + rowItem.data.manager + "'}";
      });
 
      // optional - update the text area that shows the selection details
      $page.variables.currentSelectionString = selectionString;
    }
    );
  }
}
