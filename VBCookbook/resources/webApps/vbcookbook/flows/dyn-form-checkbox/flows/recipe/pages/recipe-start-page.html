Add a Dynamic Form and use the Configure as Edit Form quick start to display employee details in the dynamic form. In this example, the Employee dynamic form displays three boolean fields (Safety, Security, and Ethical Training) and our goal is to edit these fields using one Checkbox Set component.

Create a Checkbox Field Template

  1. Create a virtual field named trainingVF and add the individual training fields to it (Safety, and so on).
  2. Add the trainingVF virtual field to the layout and create a field template for it.
  3. In the Templates tab, select the Training VF field template and, from the Components palette, drag and drop a Checkbox Set component onto the field template.

  4. Add two JavaScript functions, one to get the selected checkbox values and the other to update changed values.

    The Checkbox Set component reads and writes selected values from arrays of strings. Therefore, we need to convert the values of the three individual fields and write them into the array (as well as read them from it). And because the individual field values have the same type (boolean Yes/No), we need to create an artificial value representing each individual training field being set.

    Expand to view code 
    getTrainingsValue(fields) {
  let trainingArray = [];
  if (fields.safetyTraining() === "Yes") {
    trainingArray.push("safety");
  }
  if (fields.ethicalTraining() === "Yes") {
    trainingArray.push("ethical");
  }
  if (fields.securityTraining() === "Yes") {
    trainingArray.push("security");
  }
  return trainingArray;
}

storeTrainingsChanges(event, fields) {
  const value = event.detail.value;
  let v = value.includes("safety") ? "Yes" : "No";
  if (v !== fields.safetyTraining) {
    fields.safetyTraining( v );
  }
  v = value.includes("ethical") ? "Yes" : "No";
  if (v !== fields.ethicalTraining) {
    fields.ethicalTraining( v );
  }
  v = value.includes("security") ? "Yes" : "No";
  if (v !== fields.securityTraining) {
    fields.securityTraining( v );
  }
}

  5. In the Data tab of the Checkbox Set component's Properties pane, set the Value property to "[[ $functions.getTrainingsValue($value) ]]".

    Note the use of square brackets which means that the value is not writable, but the function result value initializes the Checkbox Set component's state.

  6. In Code view, add an on-value-changed event to the Checkbox Set component to fire an event which calls the storeTrainingsChanges function. This propagates the change in the Checkbox Set component state back to the underlying virtual object fields. Also add a static list with the three training options.

    <oj-checkboxset
      label-hint="Trainings Completed" 
      value="[[ $functions.getTrainingsValue($value) ]]"
      on-value-changed="[[ function (event) { $functions.storeTrainingsChanges(event, $value) } ]]">
    <oj-option value="safety">Safety and Wellbing</oj-option>
    <oj-option value="ethical">Code of Ethics</oj-option>
    <oj-option value="security">Security Training</oj-option>
  </oj-checkboxset>
