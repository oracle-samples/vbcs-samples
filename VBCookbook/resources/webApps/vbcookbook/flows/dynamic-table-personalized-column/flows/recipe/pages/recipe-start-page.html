Create a Dynamic Table

  1. In the Page Designer, drag and drop the Dynamic Table component onto the template.
  2. In the Quick Start tab of the Properties pane, click Configure Layout.
  3. In the Configure Layout dialog that appears, choose the business object or REST endpoint that you want to use as the data source for the form, and click Next.
  4. In the Select Rule Set page of the Configure Layout dialog, click New Rule Set to define your own display logic, and enter a rule set label and ID, such as tableExampleLayout RuleSet.
  5. In the Fields section, select the following fields, and click Next, and then click Finish.
    • firstName
    • lastName
    • phoneNumber
    • email
    • salary

Enable Personalization of Columns

  1. In the Variables tab, create a new variable named personalization of type Object.

  2. In the Properties pane for the newly-created personalization variable, set the Persisted property to Device.

    This property enables Dynamic Table columns to be persisted on the device where the Dynamic Table is used and restored when the page is reopened.

  3. In the Code view of the Page Designer, set the Dynamic Table's private-state property to {{ $variables.personalization }} and the column-management property to enabled.

    <oj-dynamic-table ... private-state="{{ $variables.personalization }}" column-management="enabled" ...>

    The personalization variable stores the order of columns and which columns are visible or hidden, while the column-management property adds a column customization button to the top right corner of the Dynamic Table.
