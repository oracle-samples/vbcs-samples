Prerequisite: Please refer to the Batch Editable Table (BDP) recipe to create an editable table.

Configure an Add Row Feature for Editable Table
  1. In the Variables tab of the page, create a variable named blankRowBuffer of type EmployeeType.
    This variable holds the data values for new rows.
  2. In the Code view of the Page Designer tab, add a template tag to the table with a slot attribute value of addRowTemplate, and the data-oj-as attribute set to addRow.
  3. Use <tr> and <td> tags inside the template tag to add the field components such as oj-input-text for first and last name, oj-select-single for job field, and so on.
  4. In the last column, add Submit and Cancel buttons that display using icons (display="icons") to submit or discard the changes that the user makes. Expand to view code 
      <template slot="addRowTemplate" data-oj-as="addRow">
          <tr>
            <td>
              <oj-input-text class="addRowEditable" value="{{ $variables.blankRowBuffer.firstName }}" required="true">
              </oj-input-text>
            </td>
            <td>
              <oj-input-text class="addRowEditable" value="{{ $variables.blankRowBuffer.lastName }}" required="true">
              </oj-input-text>
            </td>
            <td>
              <oj-select-single class="addRowEditable" data="[[$page.variables.jobListSDP]]"
                value="{{ $page.variables.blankRowBuffer.job }}" item-text="jobTitle"
                value-item="{{ { key: $page.variables.blankRowBuffer.job, data: { id: $page.variables.blankRowBuffer.job, jobTitle: $page.variables.blankRowBuffer.jobObject.items[0].jobTitle }} }}"
                on-oj-value-action="[[$listeners.selectValue]]" :id="[[ 'oj_select_single_addRow'+$current.key ]]"
                required="true"></oj-select-single>
            </td>
            <td>
              <oj-input-number class="addRowEditable" value="{{ $variables.blankRowBuffer.salary }}"
                validators="{{[$functions.salaryInRangeValidator($page.variables.blankRowBuffer, $page.variables.disableRowEditExit)]}}"
                converter='{"options":{"style":"currency","currency":"USD","useGrouping":true},"type":"number"}'
                required="true">
              </oj-input-number>
            </td>
            <td>
                <oj-bind-text
                  value="[[ $variables.blankRowBuffer.job ? $page.functions.getFormattedSalaryRange($page.variables.blankRowBuffer, $page.variables.disableRowEditExit) : '' ]]">
                </oj-bind-text>
            </td>
            <td>
              <oj-toolbar data-oj-clickthrough="disabled" chroming="borderless" class="oj-sm-padding-0-vertical">
                <oj-button display="icons" data-oj-clickthrough="disabled">
                  <span slot="startIcon" class="oj-ux-ico-check"></span>
                  Submit
                </oj-button>
                <oj-button display="icons" data-oj-clickthrough="disabled">
                  <span slot="startIcon" class="oj-ux-ico-multiply"></span>
                  Cancel
                </oj-button>
              </oj-toolbar>
            </td>
          </tr>
        </template>
  5. In the template tag, select the Submit button and, in the Events tab of the Properties pane, add an ojAction event to create a corresponding action chain.
  6. In the action chain, add a Code action to call the following code: 
    current.submitAddRow(false);
  7. Repeat the same steps for the Cancel button, and in the action chain, add a Code action to call the following code: 
    current.submitAddRow(true);

Add Validation and Submit Functionality for the New Row

  1. Notice that components in the addRowTemplate slot are annotated with the addRowEditable class, as in the following example:
    <oj-input-text class="addRowEditable" value
  2. Enhance the isFormValid function (which was created in Editable Table BDP recipe) with functionality to validate also add row data: Expand to view enhanced function 
        isFormValid(event, rowType) {
      const detail = event.detail;
      if (detail !== undefined && detail.cancelEdit === true) {
        // skip validation
        return true;
      }
      // iterate over editable fields which are marked with "editable" class
      // and make sure they are valid:
      let table = event.target;
      if (table === undefined) {
        table = event.detail.originalEvent.target;
      }
      let editables = [];
      if (rowType === "addRow") {
        editables = table.querySelectorAll(".addRowEditable");
      } else {
        editables = table.querySelectorAll(".editable");
      }
      if (detail !== undefined && detail.cancelAdd === true) {
        editables.forEach(item => item.reset());
        return true;
      }

      for (let i = 0; i < editables.length; i++) {
        let editable = editables.item(i);
        editable.validate();
        // Table does not currently support editables with async validators
        // so treating editable with 'pending' state as invalid
        if (editable.valid !== "valid") {
          return false;
        }
      }
      return true;
    }
  3. In the Page Designer, select the Table component and, in the Events tab of the Properties pane, add an ojBeforeRowAddEnd event listener.
  4. In the action chain, add a new parameter called event of type Any.
  5. In the Event Listeners tab, select the action chain, and map the new parameter to event.
  6. Still in the Events Listener tab, select the event's action chain parent node and set the Prevent Default property to: 
      [[ !$page.functions.isFormValid($event, 'addRow') ]]
    This prevents a user from creating a new row that does not pass row validation.
  7. In the action chain for the ojBeforeRowAddEnd event, we recheck the validity of the record and, if valid, we check whether the new row is being cancelled or submitted. In the case where it is being submitted, we assign the record a new unique ID, and insert it into the employeesBDP instance using the addItem function call. We follow this with a reset of the blank record variable. The code for these actions is similar to the following: Expand to view code 
          const isFormValid = $page.functions.isFormValid(event, 'addRow');

      let resetBlankRecord = false;
      
      if (isFormValid && event.detail.cancelAdd === false) {
        $page.variables.nextIdValue = $page.variables.nextIdValue + 1;
        const key = $page.variables.nextIdValue;
        const recordToInsert = JSON.parse(JSON.stringify($page.variables.blankRowBuffer));
        recordToInsert.id = key;
        $page.variables.employeesBDP.instance.addItem({metadata: { key: key }, data: recordToInsert});
        resetBlankRecord = true;
      }

      if (event.detail.cancelAdd === true) {
        resetBlankRecord = true;
      }

      if (resetBlankRecord) {
        await Actions.resetVariables(context, {
          variables: [
            '$page.variables.blankRowBuffer',
          ],
        });
      }
