To implement this recipe, you'll add a dynamic form to your page and configure it using the Configure as Edit Form quick start, in addition to adding a regular list of values for the Job field from the Job business object. Once you have completed these tasks, add a global field template to the Job field.

Add a Global Field Template to the Job Field

  1. In the Source tab, open the Employee layout's data-description-overlay.json file and add the following code under replaceMetadata: 
    "job": {
    "layoutDiscriminant" : "globalJobLOV",
    "labelHint" : "New Job"
  }
  2. Also in the Source tab, click the Create Layout icon beside dynamicLayouts and create the following files to add the code for the global field template:
    • field-templates-overlay.html
    • field-templates-overlay.json
    • helper-functions.js
  3. Open the field-templates-overlay.json file and create entries to add and map the global field template and import the helper-functions.js file. Expand to view code 
    {
"addTemplates": {
  "globalCaseInsensitiveJobLOV": {
    "title": "Global Case Insensitive Job LOV Template",
    "description": "Global Case Insensitive Job LOV Template",
    "extensible": "byReference"
  }
},
"addTemplateMap": {
  "singleValue": {
    "$byLayoutDiscriminant": {
      "globalJobLOV": "globalCaseInsensitiveJobLOV"
    }
  }
},
"imports": {
  "modules": {
    "helperFunctions": {
      "path": "./helper-functions.js"
    }
  }
}
}

  4. Open the helper-functions.js file and write a function to make a REST call that fetches jobTitles from the Job business object and another function to transform the query call from case sensitive to case insensitive.

    The transform function code is a simplistic example that you need to update to work with your backend REST API.

    Expand to view code 
    define(["knockout", 
    "vb/types/factories/serviceDataProviderFactory",
    "vb/BusinessObjectsTransforms",
], function (
  ko,
  ServiceDataProviderFactory,
  BOTransforms
) {
  "use strict";

  let sdpCache;

  const HelperFunctions = function HelperFunctions() { };

  HelperFunctions.prototype.createJobSDP = function() {
    if (sdpCache === undefined) {
      sdpCache = ko.observable();
      ServiceDataProviderFactory.createInstance({
        dataProviderOptions: {
          endpoint: "businessObjects/getall_Job",
          keyAttributes: "id",
          itemsPath: "items",
          transformsContext: {
            "vb-textFilterAttributes": [
              "jobTitle"
            ]
          },
          transforms: {
            request: {
              query: this.patchQueryURL
            }
          }
        },
      }).then((sdpInstance) => {
        sdpCache(sdpInstance);
      });

    }
    return sdpCache;
  };

  HelperFunctions.prototype.patchQueryURL = function(configuration, options, transformsContext) {
      const o = options;
      const c = configuration;
      let newUrl = c.url;
      // this is just a very simplistic example which turns
      //   "jobTitle LIKE '%searchTermHere%'"
      // into
      //   "UPPER(jobTitle) LIKE UPPER('%searchTermHere%')"
      // whether and how the case insensitive search is supported
      // differs per REST backend and concrete REST API specification needs to be consulted
      if (newUrl.indexOf('jobTitle%20LIKE%20') >= 0) {
        newUrl = newUrl.replace("jobTitle%20LIKE%20", "UPPER(jobTitle)%20LIKE%20");
        newUrl = newUrl.replace("%20%27", "%20UPPER(%27%25");
        newUrl = newUrl.replace("%25%27", "%25%27)");
        
      }
      c.url = newUrl;

      return c;
  };

  return new HelperFunctions();
});
  5. In the field-templates-overlay.html file, add the template for the Job field. It uses a custom SDP with a case-insensitive REST lookup. 
    <template id='globalCaseInsensitiveJobLOV'>
  <oj-select-single label-hint="[[ $labelHint ]]" value="{{ $value }}"
    data="[[$modules.helperFunctions.createJobSDP()]]" item-text="jobTitle"></oj-select-single>
</template>
